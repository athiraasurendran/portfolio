# /public/images/projects

Optional. The Selected Work section and case-study page currently work
without any project screenshots. If you'd like to add a screenshot of the
Streamlit app (e.g. for extra visual context on the case-study page):

1. Add an image here, e.g. `stock-forecaster-app.png`.
2. Reference it with Next.js's `<Image>` component from `next/image` so it's
   automatically optimized (resized, served as WebP/AVIF, lazy-loaded).

This is a nice-to-have, not required for the site to work correctly.
